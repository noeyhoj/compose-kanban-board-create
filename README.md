## UI 테스트

- [ ] 상태 버튼을 클릭 했을 때 다른 상태 버튼은 선택되지 않아야 한다.
- [ ] 담당자 버튼을 클릭 했을 때 다른 상태 버튼은 선택되지 않아야 한다.
- [ ] 제목 검증 혹은 태그 검증에 실패시 생성 버튼 비활성화
- [ ] 텍스트 필드에 입력한 내용이 입력한대로 출력되어야 한다.
- [ ] 제목 검증 혹은 태그 검증에 실패시 생성 버튼을 누르면 제목과 태그에서 에러 표시가 출력되야 한다.
